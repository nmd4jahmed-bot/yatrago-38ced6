# yatrago Travel

## Project overview

Demo is an independently branded travel discovery website. It provides interactive flight, hotel, holiday, bus, and visa search previews, destination inspiration, sample promotions, and help content. It is not connected to travel inventory, reservations, visa services, or payment providers.

## Architecture

- React 19 and TypeScript render the interface through TanStack Start and TanStack Router.
- `src/routes/index.tsx` contains the landing page, service search forms, static destination content, offers, and accessible native-dialog previews.
- `src/routes/__root.tsx` provides the HTML shell, Demo share metadata, and favicon configuration.
- `src/styles.css` defines the visual system, responsive layouts, and reduced-motion behavior.
- `src/router.tsx` initializes routing. The route tree is generated by the framework; do not edit generated routing files.
- `public/img/` contains bundled photographs. The tropical hero was generated through Netlify AI Gateway; destination photos were sourced from Unsplash.
- `public/favicon.svg` is the custom Demo brand mark.
- `vite.config.ts` integrates TanStack Start, React, Tailwind CSS, and Netlify.
- `netlify.toml` configures the deployment.

## Conventions

- Use descriptive TypeScript identifiers, function components, and React hooks for transient interface state.
- Use the existing cream, forest-green, and muted accent palette. Typography uses DM Sans, Manrope, and Playfair Display.
- Keep responsive styles in the existing stylesheet and maintain keyboard focus indicators, native form labels, dialog keyboard support, and reduced-motion support.
- Reference bundled photos through Netlify Image CDN using the `image` helper; do not ship full-resolution originals to page visitors.
- All travel fares, offers, and itineraries are illustrative. Preserve clear demo disclosures and never imply a reservation or payment has occurred.
- Search state is temporary and does not require persistence. If future features introduce saved trips, accounts, bookings, or other persistent records, use Netlify Database with Drizzle after reading the relevant platform skills. Do not use local storage or local files for persistent application records.
- No AI service is called by the deployed application. The generated hero is a static asset, not a user-facing image-generation feature.

## Development

Install dependencies with `pnpm install` and run locally with `pnpm dev`. Netlify development emulation can be started with `netlify dev --port 8889`. The platform validates production builds automatically; do not run build, test, type-check, or dev-server commands during an agent session when the task instructions prohibit them.
